# 🎯 TK KOL Finder

> 发现 TikTok 达人就这么简单 ✨

一个专为营销人员设计的 TikTok 达人发现工具，帮你快速找到最合适的 KOL 进行商业合作。

---

## 🎯 这个工具能做什么？

作为营销人员，你是否也曾为这些问题头疼 😩：

- 在 TikTok 上找达人，纯靠手动搜索，效率低到哭 😭
- 筛出来的达人，邮箱都没有，根本没法联系 📧❌
- 不知道这个达人值不值得合作，拍了半天发现是坑 💰💔

**TK KOL Finder 就是来救场的！** 🚀

帮你自动搜索 + 多维筛选 + 智能评分，一键找到那些**有邮箱**、**活跃度高**、**有商业经验**的优质达人。

---

## 🎨 核心功能

### 🔍 智能搜索
- **多关键词组合**：beauty + skincare + makeup，一次搜个够
- **标签式输入**：输入一个按逗号，想搜几个搜几个
- **实时预览**：输入关键词自动变成标签，一目了然

### 📊 多维筛选

| 筛选维度 | 说明 |
|---------|------|
| 粉丝量区间 | `<1K` 到 `>1M`，7 个档位任选 |
| 达人评级 | A/B/C 级，按质量过滤 |
| 排序方式 | 综合评分 / 粉丝量 / 播放量 / 邮箱优先 |

### 💯 9 维度智能评分（120分）

每个达人都会得到一个综合评分，从 5 个维度全面评估：

| 大方向 | 维度 | 分值 |
|--------|------|------|
| 📞 可联系性 | 有邮箱、建联信号、落地页 | 45 |
| 📈 规模匹配 | 粉丝区间 | 20 |
| 🎯 品类相关性 | Bio品类匹配、场景词来源 | 25 |
| 💼 商业经验 | 竞品词来源 | 15 |
| 🎬 内容能力 | 活跃创作者、爆款视频 | 15 |

**A 级达人（≥90分）**：优质合作对象，闭眼选都不会错 👍

### ⭐ 收藏管理
- 一键收藏心仪达人，心动不留遗憾 ❤️
- 收藏列表支持 CSV 导出，方便整理归档 📁
- localStorage 本地存储，数据安全不丢失 🔒

## 🚀 快速上手

### 1️⃣ 克隆项目

```bash
git clone https://github.com/your-username/tk-kol-finder.git
cd tk-kol-finder
```

### 2️⃣ 安装依赖

```bash
npm install
```

### 3️⃣ 配置 API Key

复制 `.env.example` 为 `.env`，填入你的 TikHub API Key：

```env
TIKHUB_API_KEY=your_api_key_here
```

> 💡 没有 TikHub API Key？去 [tikhub.io](https://tikhub.io) 注册一个

### 4️⃣ 启动服务

```bash
npm run dev
```

然后打开 [http://localhost:3010](http://localhost:3010)，开始你的达人发现之旅 🚀

## 📖 使用指南

### 搜索篇

1. 在输入框输入关键词，比如 `beauty`
2. 按**逗号**或**回车**添加更多关键词，如 `skincare`、`makeup`
3. 选择你想要的**粉丝量区间**和**达人评级**
4. 点击**立即搜集** ✨

### 筛选篇

- 想要最优质的达人？→ 选 **A级** + **综合评分**排序
- 预算有限想要性价比？→ 选 **1K-10K** 区间
- 只找能直接联系的？→ 选 **邮箱优先**排序

### 收藏篇

看到心仪的达人？点击卡片上的 ❤️ 收藏起来！支持批量导出 CSV，整理客户列表超方便 📋
